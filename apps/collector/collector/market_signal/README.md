# [시장 시그널] 파이프라인

종목 모니터 **우상단 카드**(ETF 순매수 모니터 자리, 2026-08-31 교체)의 엔진.
일별 종가만으로 "무엇이 튀었고, 왜 튀었고, 근거가 있는가"를 답한다.

```
price_monitor.xlsx (일별 종가 87시장)
   │
   ├─ 1단  signal_rules.detect_all      "튀었다"        → 하루 8.6건
   │        └ indicators.compute        지표 7군 40여개
   ├─ 2단  graph.interpret               "왜 튀었나"     → 가설 6종, 묶음 접기
   │        ├ knowledge.ttl              손으로 쓴 인과 구조 (불변)
   │        └ markets.ttl                매일 굽는 관측  (build_graph.py)
   ├─ 3단  news.gather                   "근거가 있나"   → Google RSS 48h
   └─ pipeline.build_market_signal       카드 payload   → /market-signal
```

## ★★설계에서 흔들면 안 되는 것 4가지

**1. 고정 % 임계를 쓰지 않는다.**
주간 |수익률| ≥5% 발화율 실측: DXY **0.0%**(5년 반 0건) · S&P500 3.4% · WTI 30.3% ·
ETH **47.1%**. 같은 임계가 어떤 시장엔 5.3σ, 어떤 시장엔 0.56σ다.
→ **그 시장 자신의 분위수**로 자른다. z 도 아니다(꼬리 두께가 시장마다 달라 같은 z 가
다른 희소도를 뜻한다). 이 원칙 때문에 RSI 를 일부러 뺐다 — 임계 70/30 이 고정값이다.

**2. 분포 추정에는 이월(ffill 복사본)을 걷어낸 시계열을 쓴다.**
시트가 주말·휴일을 forward-fill 하므로 0% 가 분포에 섞여 σ 가 과소 추정되고 z 가 통째로
부풀려진다. 상관에서는 더 나쁘다 — 주말 0% 가 양쪽에 같이 끼어 **거짓 상관**이 된다.

**3. 기간 이동은 영업일 위치(shift)가 아니라 달력 일수로 한다.**
이월을 걷어낸 시계열에서 `shift(5)` 를 하면 달력으로 열흘 넘게 거슬러 간다.

**4. 금리는 어디서나 부호를 뒤집어야 한다.**
금리 상승 = 채권 **약세**. 체제 판정(`classify_regime`)·문장 생성(`price_dir`)·이웃
비교(`_same_dir`) 세 군데 전부. 안 지키면 "2Y 단독 강세"(금리 +23bp인데) 가 나간다.

## ttl 두 개를 가른 이유

| | knowledge.ttl | markets.ttl |
|---|---|---|
| 무엇 | 손으로 쓴 **암묵지** | 매일 굽는 **관측** |
| 내용 | 묶음·동인·전이·역상관·가설 템플릿 | 체제·상관 225간선·매크로동조 96 |
| 변하나 | 안 변한다("구리→호주") | 매일 변한다(상관은 체제 따라) |
| 어디 | 패키지 안(소스) | **`/app/.cache/market_signal/`** (named volume) |

★섞어 두면 매일 손으로 쓴 지식까지 덮어쓴다.
★★`markets.ttl` 을 패키지에 두면 안 된다 — git 에 커밋되고, 빌드 시점의 낡은 데이터가
이미지에 구워져 배포되고, 컨테이너 재생성 때 되돌아간다(2026-08-31 8회차에 고침).

## 컷을 바꾸면 **반드시 다시 재야 하는 것**

| 상수 | 파일 | 바꾸면 재측정 |
|---|---|---|
| `PCT_HI/LO` 0.995/0.005 | signal_rules | **발화율**(목표 하루 3~8건) |
| `RANGE_NEW_D` 90 | signal_rules | 발화율 — 이 룰이 한때 전체의 29%였다 |
| `STREAK_CUT` 8 | signal_rules | 발화율 |
| `CORR_MIN` 0.55 | build_graph | markets.ttl 크기·간선 수 |
| `CORR_STRONG` 0.70 | graph | Idiosyncratic 비중(목표 ~30%) |
| `RULE_HORIZON` | graph | Idiosyncratic 비중 ← **가장 민감했다** |
| `SUPPORT_MIN` 2.0 | news | 근거 확보율 |
| `REPEAT_PENALTY` 0.45 | pipeline | 카드가 며칠씩 고이는가 |

재측정 방법은 `tests/` 옆의 백테스트가 아니라 **직접 짜야 한다**(표본일을 돌며
`detect_all`/`interpret` 을 부르면 된다). 과거 날짜로 돌릴 땐 **`markets.ttl` 도 그날
기준으로 다시 구울 것** — 안 그러면 과거 시그널을 오늘의 이웃 값과 비교하게 된다.

## 알려진 한계

- **전이 경로가 10개뿐이다.** 데이터로 더 찾으려 했으나 실패했다(lead-lag 채굴 0쌍).
  손으로 쓴 것 중 1/4은 2년 실측이 반박해서 지웠다(WTI→사우디는 동시상관이 −0.13이었다).
  늘리려면 **도메인 지식이 필요하다**.
- **구조적 역상관이 거의 없다.** 87시장 3,741쌍에서 |r|≥0.45인 음의 상관이 1쌍
  (USDJPY↔JPYKRW, 기계적)뿐 — 대부분 위험자산이라 같이 움직인다.
  `InversionBreak` 가 14일에 1건인 건 룰이 나빠서가 아니라 데이터가 그렇다.
- **AI 를 부르지 않는다.** 2단이 내는 `summary`("암호화폐 전반 강세"=9자)가 이미
  요구 규격인 "15자 내외 요약"이다. 컨테이너에 `claude` 가 없기도 하지만, 애초에
  판단이 1·2단에서 끝나 LLM 이 할 일이 없다. 윤문을 얹고 싶으면 그때 밖에서 부른다.
